# G_plane_intersection
Python code to calculate ternary phase diagrams in the MgSiO3-Fe-H2 system (see Young et al. (2025, PSJ 6:2510).
G_plane_intersection_tern_hull_v10.py imports various functions from phasehull.py (written by Cornelis Dullemond, see Dullemond and Young A&A, 2026) 
Set conditions in the block starting at line 44 (T, P, wtpercent_H2 for marker on ternary).
